Q1. Write a program that displays current date and time in your browser.

CODE:

Q2. Write a program that alerts the current month in words. For example December.

CODE:

  var monthNames = ["January", "February", "March", "April", "May", "June", 
                    "July", "August", "September", "October", "November", "December"];
  
  var currentDate = new Date();
  var monthIndex = currentDate.getMonth();
  var currentMonth = monthNames[monthIndex];
  
  alert("Current month: " + currentMonth);
  
  var result = "Current month: " + currentMonth;
  displayOutput("output2", result);

Q6. Write a program that determines the minutes since midnight, Jan. 1, 1970 and displays it.

CODE:


        var currentDate = new Date();
        var startOf1970 = new Date(1970, 0, 1);

       
        var elapsedMilli = currentDate - startOf1970;
        var elapsedMinutes = elapsedMilli / (1000 * 60); 

        var result =
          "Current Date: " +
          currentDate +
          "\nElapsed milliseconds since January 1, 1970: " +
          elapsedMilli +
          "\nElapsed minutes since January 1, 1970: " +
          elapsedMinutes;

        displayOutput("output6", result);

Q9. Create a date object of the starting date of this Ramadan and alert the number of days past since 1st Ramadan? (Note: 1st Ramadan was on June 18, 2015).

CODE:


  var ramadanStart = new Date(2015, 5, 18);
  var currentDate = new Date();

  
  var diffTime = currentDate - ramadanStart; 
  var diffDays = diffTime / (1000 * 60 * 60 * 24); 

  var result = Math.floor(diffDays) + " days have passed since 1st Ramadan, 2015";
  
  alert(result);
  displayOutput("output9", result);

Q10. Write a program that displays in your browser the seconds that elapsed between the reference date and the beginning of 2015.

Q11. Create a Date object for the current date and time. Extract the hours, reset the date object an hour ahead and finally display the date object in your browser.

CODE:

var currentDate = new Date();
var currentHours = currentDate.getHours();
var updatedDate = new Date();
updatedDate.setHours(currentHours + 1);
var result = "current date: " + currentDate + "\n1 hour ahead, it will be " + updatedDate;
displayOutput("output11", result);

Q12. Write a program that creates a date object and show the date in an alert box that is reset to 100 years back.

CODE:

var currentDate = new Date();
var pastDate = new Date();
pastDate.setFullYear(currentDate.getFullYear() - 100);
alert("100 years back, it was " + pastDate);
var result = "current date: " + currentDate + "\n100 years back, it was " + pastDate;
displayOutput("output12", result);

Q13. Write a program to ask the user about his age. Calculate and show his birth year in your browser.

CODE:

var age = prompt("Enter your age:");
if (age) {
  var currentYear = new Date().getFullYear();
  var birthYear = currentYear - parseInt(age);
  var result = "Your age is " + age + "\nYour birth year is " + birthYear;
  displayOutput("output13", result);
}

Helper function to show output on screen

CODE:

function displayOutput(id, result) {
  var element = document.getElementById(id);
  element.style.display = "block";
  element.innerText = result;
}
